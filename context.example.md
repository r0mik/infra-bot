The homelab:
- production: node "production" (hostname "server1"), 4 cores, 16 GiB RAM, 512 GB NVMe. k3s cluster "production": monitoring (Prometheus, Alertmanager, Grafana, Loki, Alloy), reverse proxy with TLS for *.example.home.arpa, Git server, object storage, registry, Argo CD, a few apps. Primary DNS runs in Docker outside k8s.
- staging: node "staging", 6 cores, 16 GiB RAM, 256 GB NVMe. k3s cluster "staging": apps under test, secondary DNS (Docker), node-exporter (Docker).
- Metric labels: env (production/staging/network), node; Kubernetes series also cluster. Staging alerts don't go to Telegram but are in Alertmanager. Handy metrics: up, node_load1, node_cpu_seconds_total, node_memory_MemAvailable_bytes, node_filesystem_avail_bytes{fstype=~"ext4|xfs"}, node_hwmon_temp_celsius, node_vmstat_oom_kill, kube_pod_container_status_restarts_total, container_memory_working_set_bytes, probe_success. Use find_metrics for more.
- Logs in Loki: platform namespaces' pods, the systemd journal (k3s, containerd, docker, ssh, kernel) and Docker containers of both nodes; app namespaces' logs only via k8s_logs.
